# 웨이퍼 인수인계 메모

## When to Use
- 사용자가 웨이퍼 관련 현장 메모(교대 메모, 장애 메모 등)를 제공하며 인수인계 정리를 요청할 때 사용한다.
- DB 조회나 데이터 분석이 필요한 요청에는 사용하지 않는다. 이 스킬은 제공된 메모 텍스트만 사용한다.

## 목적
웨이퍼 관련 현장 메모를 받으면 교대 인수인계용 세 줄 메모로 정리한다.

## 규칙

1. **입력은 제공된 메모만 사용한다.** DB 조회, 파일 검색, 세션 검색 등 외부 자료 조회를 하지 않는다. 메모에 없는 배경 지식도 보완하지 않는다.
2. **출력은 다음 세 줄로만 정리한다.** 각 줄은 아래 제목으로 시작한다.
   - `관찰 내용:` 메모에 적힌 사실·측정값·증상
   - `확인할 점:` 메모에서 불명확하거나 확인이 필요한 항목
   - `다음 교대 작업:` 메모에 지시된 후속 작업
3. **메모에 없는 값은 추측하지 않는다.** 수치, lot/wafer 번호, 장비명, 시각 등이 메모에 없으면 해당 위치에 `미기재`라고 적는다. 빈 칸이나 예상값으로 채우지 않는다.
4. **세 줄이 모두 비어 있어도 억지로 채우지 않는다.** 해당 줄에 들어갈 내용이 메모에 전혀 없으면 `미기재`만 적는다.
5. 메모 원문의 식별자(LOT_ID, WFID, 장비 ID 등)는 표기 그대로 보존한다. 정규화하거나 수정하지 않는다.

## 출력 형식 예시

```
관찰 내용: <메모에 적힌 관찰 사실>
확인할 점: <메모상 확인이 필요한 항목>
다음 교대 작업: <메모에 지시된 후속 작업>
```

## 절차

1. 사용자가 제공한 메모 전문을 읽는다.
2. 메모 내용을 관찰 / 확인 필요 / 후속 작업으로 분류한다.
3. 분류 기준이 애매한 문장은 사실인지 확인 필요 항목인지 메모 서술에 따라 판단하고, 판단이 불가능하면 `확인할 점`에 넣는다.
4. 세 줄 메모를 한국어로 작성해 답한다. 추가 도구 호출은 불필요하다.
