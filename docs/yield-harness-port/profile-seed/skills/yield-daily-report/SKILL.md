# 수율일보 (Yield Daily Report)

기존 yield-summary(수율 요약) 스킬과는 별개의 일보 절차다.

첫 도구 호출은 render_yield_table에 analysis={months:3,weeks:4,days:3,parameters_per_direction:3,bins_per_test:10}을 전달하는 것이다. 이 도구에 제품 선택창이 내장되어 있다. 제품이 주어지지 않았으면 lot_cd 필드를 생략하고 바로 호출한다. 도구가 DB 제품 목록을 표시하고 사용자의 선택을 받아 같은 호출에서 조회를 끝낸다.
사용자가 지정한 제품은 lot_cd, 명시적으로 좁힌 검사만 analysis.tests, 지정한 기준일만 analysis.as_of에 전달한다. 기본은 해당 제품의 PT1H TEST와 PT1C TEST이며 기준일은 DB 최신 측정일이다.
산점도와 BIN 맵 비교 주차는 결과의 comparison.previous_week와 current_week를 사용한다. 반환된 범위와 순위로 결론을 먼저 쓰고 artifact_refs의 markdown을 순서대로 모두 한 번씩 표시한다.
기준일은 지정일 또는 해당 제품의 최신 측정일이고 실제 날짜와 주 경계를 표시한다.
핵심 결론 뒤에 다음 세 구역을 이 순서로 출력한다.

## 1. 기간별 수율표 3개

기준일이 속한 기간부터 월별 최근 3개월, 주별 최근 4주, 일별 최근 3일을 각각 **독립된 창**으로 조회하고 월→주→일 순서로 실제 표를 붙인다.
세 단위를 한 기간으로 잘라 대체하지 않는다.

## 2. 최근 두 주간 웨이퍼 단위 산점도

직전 주와 최근 주를 비교하고, 웨이퍼별 측정 결과에서 열화 상위 3개와 개선 상위 3개 파라미터를 각각 고른다.
공정 메타데이터나 사용자 기준으로 증감의 유불리(목표값이 있으면 목표와의 거리)를 판단한다.
단위가 다른 파라미터의 순위는 비교 가능한 기준으로 산정하고 사용한 기준·표본 수를 표시한다.
방향을 판정할 근거가 없으면 임의로 열화/개선으로 분류하지 않는다.
웨이퍼 재측정 정책을 적용한 실제 조회 결과로 파라미터별 산점도 6개를 그린다.
점은 웨이퍼 측정값 하나, x축은 측정일시, y축은 파라미터 값과 단위, 색은 비교 주차, LOT·웨이퍼 번호 식별 가능.
주 평균이나 LOT 평균으로 점을 대체하지 않는다.
적격 항목이 3개보다 적으면 확인된 수와 사유를 표시한다.

## 3. 산점도 아래 BIN별 CUMMAP과 델타맵

같은 두 주의 동일 제품·맵 검사 범위에서 열은 동일 BIN 10개로 고정한다.
요청 BIN이 없으면 두 주 합산 발생 건수가 많은 불량 BIN 10개를 사용하고, 사용 가능한 BIN이 적으면 실제 개수만 그린다.
BIN 정의와 좌표별 유효 관측 수를 사용한다.
1행은 직전 주 CUMMAP 10개, 2행은 최근 주 CUMMAP 10개, 3행은 같은 BIN/다이 좌표별 최근 주 발생률 − 직전 주 발생률 델타맵 10개(%p).
주차 간 좌표와 BIN 순서를 맞추고 두 주의 맵에는 같은 발생률 색 척도, 델타에는 0 중심 발산 척도를 사용한다.
관측되지 않은 좌표는 결측으로 표시한다.
실제 조회 결과로 3행 비교 그림을 렌더링하여 표시한다.

## 공통 규칙

- 특정 제품·날짜·파라미터·BIN 값은 고정하지 않는다.
- 표나 그림이 생성되지 않으면 해당 구역의 실제 제한을 밝힌다.
