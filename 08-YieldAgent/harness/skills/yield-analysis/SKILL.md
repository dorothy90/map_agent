# 수율 분석

`inspect_yield_coverage`는 실제 자료의 기간을 확인한다. 사용자가 지정한 기간과 관측된 기간을 구분한다. 최근 자료가 오래됐어도 요청 기간을 임의로 이동시키지 않는다.

기간 집계는 `query_yield`, 웨이퍼 원본/순위는 `query_wafer_yield`의 상세 schema를 읽는다. 산점도는 시각화이고 전체 모집단 순위를 대신하지 않는다. 동률과 자료 없는 기간을 보존한다.

PT1H 파라미터 값, PT1H A-bin 전체 pass 비율, PT1C 원본 지표, GMS%는 다른 지표다. 반환된 단위·분모·재측정 정책·지표 방향을 기준으로 설명한다. 정의가 미확정이면 사용자가 필요한 metric을 선택하게 한다. `analyze_yield`의 변화량과 표본 수를 함께 읽는다.

계산은 저장된 전체 표에서 수행한다. 여러 표는 `tables[result_id][table_id]`로 구분하고 결과는 이름 있는 `emit_table`로 저장한다. 실제 조회가 일부이면 전체 최저·전체 평균을 확정하지 않는다.

기간별 수율 변화의 열화는 `analyze_yield`의 최신 두 기간 변화와 방향을 근거로 삼는다. WADS 검출은 별도의 보고서 근거이며 일반적인 수율 변화 분석을 자동으로 대체하지 않는다. 이미 저장된 수율표가 있으면 Python 도구로 동일 지표 정의에 따라 계산해 재사용할 수 있다.

특정 불량 수율과 하위 wafer는 `query_defect_yield`를 사용한다. 수율은 해당 불량 bin die를 제외한 비율이며 전체 A-bin 수율과 다르다. 지원하는 PT1H 파라미터명은 기존 맵 정의를 사용한다. WADS 이름의 괄호 문자를 bin으로 추정하지 않는다. 매핑이 없으면 제한을 알리고 다른 지표로 몰래 대체하지 않는다.

여러 열화 항목 중 총 N개 wafer를 요청하면 선택한 불량들의 합집합 수율로 총 N개를 선정한다는 기준을 명시한다. 항목별 N개로 확대하거나 대표 항목 하나로 축소하지 않는다. 항목별 요청이면 별도로 조회한다. 의미가 확정되지 않으면 필요한 조건을 짧게 확인한다. `include_binmap=true`는 순위와 같은 측정 건의 이미지를 함께 생성한다. 조회 기간을 수율 분석과 맞추고 오늘 이후의 날짜로 확장하지 않는다.

도구 입력 오류는 허용 입력 조합을 확인해 수정한다. 같은 잘못된 호출을 반복하지 않는다. 기존 `query_wafer_yield`의 pass_rate와 parameter를 함께 지정할 수 없다.

열화 원인 요청에서는 변화가 관측된 기간·검사·항목을 근거로 WADS 원문·해당 웨이퍼·LOT/불량이력을 조사한다. 검출 빈도나 시간적 동반 변화만으로 공정 원인을 확정하지 않는다. 최종 답변은 관측된 변화, 관련 근거, 원인 가설, 확인하지 못한 사항을 구분한다.
