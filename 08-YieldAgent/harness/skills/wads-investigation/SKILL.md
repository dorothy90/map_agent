# WADS 조사

제품과 기간이 정해져 있으면 `query_wads`로 해당 범위를 조회한다. 최신 발행 시점이나 제품 범위를 알아야 할 때 `inspect_wads_coverage`를 사용한다. 기간이나 제품을 도구에서 확인할 수 있으면 사용자에게 반복해서 요구하지 않는다.

`reports`와 `report_wafers`는 다른 모집단이다. 보고서 건수는 report_id 기준으로, 웨이퍼 통계는 LOT/WF 식별자와 검사·측정 범위를 명시해 계산한다. 조인으로 늘어난 행 수를 보고서 건수로 사용하지 않는다. `join_coverage`의 미연결 수와 실제 관측 범위를 함께 보고한다.

이미 조회한 범위의 후속 요청은 저장된 전체 `reports`·`report_wafers`를 재사용해 report_id로 선택한다. 새 조회의 limit는 보고서 수가 아닌 조인 행 상한이므로 일부 행만으로 한 보고서의 전체 웨이퍼라고 판단하지 않는다. 원문은 `get_wads_report`로 정확한 report_id와 source_result_id를 선택한다. 사용자에게 HTML을 제공하는 것과 모델이 내용을 읽는 것은 다르다. 본문 조사가 필요하면 저장된 artifact를 `read_artifact_text`로 읽는다. 발행 메타데이터와 본문 날짜가 다르면 차이를 설명하고 원문을 수정하지 않는다.

후속 맵/이력은 선택한 보고서의 GROUPKEY·LOT·WF를 사용한다. 보고서 연결이 날짜 단위인지 정확한 측정 시점인지 결과 메타데이터를 확인한다. 검출은 원인 확정이 아니다. 독립적으로 조사할 이력이 있으면 필요한 결과 참조와 좁은 질문만 위임한다.
