# 불량 원인 조사

현재 관측한 제품·기간·검사·파라미터·LOT를 조회 결과에서 확보한다. `query_lot_history`는 서로 다른 5개 이력 테이블을 반환하며 위험도는 기존 규칙에 따른 표시다.

`search_fail_history`는 검색 모드와 가용성을 확인해 사용한다. 제목·짧은 snippet만으로 조치/원인을 확정하지 말고 필요한 문서는 `get_history_document`로 본문을 읽는다. 위키 요약은 원문 문서 ID와 확인 시점이 있는 참고 자료이며 현재 관측을 대체하지 않는다.

`query_relation`의 관련 공정 후보와 `query_good_bad_groups`의 LOT 그룹 자체는 상관계수나 인과관계 결과가 아니다. 기간 필터가 지원되지 않으면 현재 기간의 양불 집합이라고 표현하지 않는다.

`analyze_mining`은 실제 서비스가 연결돼 있을 때만 사용할 수 있다. 서비스 미연결이면 기존 수율·WADS·맵·이력에서 가능한 결론을 먼저 정리한다. 마이닝 지표는 인과 확률이 아니다.

관측 사실, 유사한 과거 사례, 원인 가설, 반증/미확인 항목을 구분한다. 추가 자료가 결론을 바꿀 수 있는 범위에서 조사하고, 남은 예산 안에서 사용자에게 유용한 결론을 작성한다.
