# 보고서 작성

사용자가 원하는 제품·기간·목적에 맞는 결과 ID를 선택하고 순서를 정한다. 비교할 두 제품/기간은 각각 보존한다. 계산표, WADS 통계, 원문, LOT/불량이력, 맵이 실제 내보내기에 반영됐는지 확인한다.

`export_report`의 반환 값에서 사용된 표·산출물·출처를 확인한다. 파일 생성만으로 분석 내용까지 완료됐다고 판단하지 않는다.

분석을 수행하지 않음, 분석했지만 이상이 없음, 이상을 관측함, 일부만 분석함을 구분한다. 단위 미확정 값에 임의의 %를 붙이지 않는다. 원인 가설은 확정 원인과 분리하고 자료 부족도 문서에 보존한다.

최종 안내에는 문서 링크와 핵심 결론을 제공한다. 모든 표를 답변 본문에 다시 복사할 필요는 없다.
