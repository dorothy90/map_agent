# Harness Console 구현 계획

- 기존 API만 사용하고 이 디렉터리 밖의 파일은 변경하지 않는다.
- 회색 바탕, 청회색 강조, 시스템 sans-serif 본문과 monospace 코드, 왼쪽 세션 목록 / 가운데 대화 / 오른쪽 실행 정보로 구성한다. 모바일에서는 세션을 접고 실행 정보를 위에 표시한다.
- fetch 기반 SSE 파서와 sequence 중복 제거를 먼저 검증한다. 각 실행이 독립적으로 이벤트를 재생하며 연결 종료 후 상태를 확인하고 실행 중일 때만 재연결한다.
- 저장된 observations로 인자, 검증 결과, named table, 파일을 보완한다. 입력 제출 후 같은 실행에 재연결한다.
- React 컴포넌트로 세션, 실행, 도구 트리, 입력 폼, 결과 표와 blob 파일을 구현한다.
- npm install, 이벤트 계약 테스트, npm run build를 실행한다. 실제 백엔드는 읽기 요청으로 확인하며 스크린샷 실행은 사용자에게 맡긴다.
