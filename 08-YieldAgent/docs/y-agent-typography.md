# Y-Agent 글자 스타일 가이드

웹 콘솔과 데스크톱 앱은 같은 글자 기준을 사용한다. 공통 글꼴과 크기 변수는 [web.css](../harness_console/src/web/web.css)에 정의한다.

| 용도 | 크기 | CSS 변수 |
| --- | --- | --- |
| 화면 제목, 답변과 보고서의 제목 | 16px | `--yagent-font-heading` |
| 채팅 입력, 내가 보낸 메시지, 답변 본문 | 15px | `--conversation-text-font-size` |
| 일반 UI, 사이드바 메뉴, 확인 질문과 선택지 | 14px | `--yagent-font-ui` |
| 사이드바 대화 제목과 이름 편집 | 13px | 사이드바의 제목 스타일 재사용 |
| 도구 실행 기록, 실행 시간, 상태, 사용량, 보조 정보 | 12px | `--yagent-font-caption` |

- 일반 UI는 `--hermes-system-font`를 상속한다. Windows에는 Segoe UI와 맑은 고딕, macOS에는 시스템 글꼴과 Apple SD Gothic Neo를 사용할 수 있게 한다. 플랫폼별 글꼴 폭 차이를 고려해서 긴 한글 제목과 작은 창에서도 줄바꿈과 말줄임이 잘 동작하는지 확인한다.
- “수율에 대해 물어보세요” 같은 입력 안내 문구는 입력 글자의 글꼴, 크기, 굵기, 줄 높이를 상속한다. 안내 문구는 연한 색으로 구분한다.
- 조회·계산 기록에서는 `query_db` 같은 도구명, 한국어 항목 제목, 상태, 시간, 토큰 사용량에 같은 글꼴과 크기를 사용한다. 항목 제목은 중간 굵기로, 상태·시간·사용량은 색과 열 정렬로 구분한다.
- 새로운 UI를 만들 때 용도에 맞는 기존 변수를 먼저 선택한다. 새 크기나 데스크톱 전용 예외가 필요하면 이 문서에 적용 위치와 이유를 남긴다.
- 채팅에 첨부되는 HTML 보고서나 맵은 별도 문서로 렌더링될 수 있다. 해당 화면의 글꼴을 변경할 때는 산출물 자체의 스타일도 확인한다.
